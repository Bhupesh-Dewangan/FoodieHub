# 🍔 FoodieHub — Online Food Ordering App

FoodieHub is a React-based online food ordering application where users can browse meals, search items, filter by categories, add items to a cart, and place orders through a smooth checkout flow.

This project focuses on building a responsive, user-friendly frontend while implementing real-world shopping cart logic and state management.

## 🚀 Features
### 🍽️ Food Browsing

- View a list of available food items

- Clean and responsive UI

### 🔎 Search Functionality

- Search meals by name

- Real-time filtering

### 🗂️ Category Filters

- Filter food items by categories

- Improved browsing experience

### 🛒 Cart Management

- Add items to cart

- Remove items

- Update item quantities

- Real-time cart updates

### 💳 Checkout Flow

- Simple and smooth order placement process

### 📱 Responsive Design

- Works across mobile, tablet, and desktop screens

## 🛠 Tech Stack
| Layer            | Technology               |
| ---------------- | ------------------------ |

## 🚀 Getting Started
```bash
# Clone the Repository
git clone https://github.com/Bhupesh-Dewangan/FoodieHub
cd FoodieHub

# Install Dependencies
npm install

# Run the App
npm start
```

App will run at: http://localhost:3000
